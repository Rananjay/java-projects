# Bank Account Assignment

Migrated from `java-bank-account-assignment`.

## Overview

A console-based Java application that creates bank accounts, processes deposits and withdrawals, validates user input, and demonstrates custom exception handling.

## Run

```bash
javac com.va.Week4.Lab2.RananjayChauhan_F2026/src/com/va/Week4/Lab2/RananjayChauhan_F2026/*.java
java -cp com.va.Week4.Lab2.RananjayChauhan_F2026/src com.va.Week4.Lab2.RananjayChauhan_F2026.MainDriver
```

## Files

- `BankAccount.java` — bank-account model and transaction logic
- `InsufficientFundsException.java` — custom exception for insufficient funds
- `MainDriver.java` — interactive console driver

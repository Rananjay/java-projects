# Dice Roller Lab

Migrated from `Lab2_Java_Diceroller`.

## Overview

A console-based Java program that rolls four dice, calculates their total, and determines whether the roll meets the game's win or loss conditions. If needed, it rolls again and compares the result with the initial goal number.

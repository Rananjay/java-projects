# Student Management Assignment

A JavaFX application for college student registration.

## Features

- Student registration form
- Input validation for required fields and email format
- Dashboard, registration, courses, and help navigation
- Clear-form functionality

## Run

From the repository root:

```bash
mvn --projects student-management-assignment javafx:run
```

Or from this module:

```bash
mvn javafx:run
```
